# Prompt 0001

**Working Directory:** .

**Prompt:**

Assume the following on a Linux system

- A router believes my computer (IP address 10.0.10.10) is a route to 10.0.11.10
- The router will send the packets due to 10.0.11.10 to my interface
- I have on the machine a veth or other network interface NOT connected to a shared bridge that in fact has this address

Can the process in the network namespace with the veth that is 10.0.11.10 talk to the world? Can the world talk to it? Can 10.0.11.10 talk to 10.0.10.10?
